# LIFE.exe

An interactive comedy sandbox about a stickman trying to live a peaceful life while you interfere with the world around him.

## Current milestone
- Hand-drawn-inspired 2D bedroom scene with layered 2.5D lighting and depth.
- Intro screen, interactive-object discovery cues, contextual tooltips and cursor feedback.
- 12+ working bedroom interactions.
- Character mood, irritation, energy and persistent personality state.
- Cursor awareness, fourth-wall-breaking reactions and small revenge moments.
- Random environment selection on refresh and a location picker (additional scenes arrive in later milestones).

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The first release focuses on making one room feel alive before expanding to the garden, kitchen, office, bathroom and living room.
